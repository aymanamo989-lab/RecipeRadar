# RecipeRadar
A Flutter recipe discovery app featuring recipe cards, detailed recipe information, and sample data.
# RecipeRadar 🍽️

RecipeRadar is a Flutter application that helps users explore different recipes and view their cooking details through a clean and modern interface.

## Features

- Browse recipes using a responsive grid layout.
- View recipe images, names, categories, and cooking times.
- Open detailed recipe pages.
- Explore ingredients and step-by-step cooking instructions.
- Sample recipe data stored locally in Dart.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/RecipeRadar.git
```

2. Navigate to the project directory:

```bash
cd RecipeRadar
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
